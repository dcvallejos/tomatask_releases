# Tomatask — descargas

Timer Pomodoro, tareas y calendario para Windows 10/11 (64 bits).

## Qué descargar

Entrá a la [última versión](../../releases/latest) y bajá **uno** de estos archivos:

| Archivo | Para quién |
|---|---|
| `Tomatask-Setup-Asistente.exe` | **Recomendado.** Instalador con asistente: elegís la carpeta. |
| `TomataskApp-win-Setup.exe` | Instalación rápida, sin preguntas (en `%LOCALAPPDATA%\TomataskApp`). |
| `TomataskApp-win-Portable.zip` | Sin instalar: descomprimir y abrir `Tomatask.exe`. No se actualiza sola. |

No hace falta ser administrador. La app se actualiza sola al iniciar (se puede desactivar en Configuración → Sistema).

## Aviso de Windows (SmartScreen)

El instalador todavía no está firmado, así que Windows puede mostrar «Windows protegió su PC». Tocá **Más información → Ejecutar de todas formas**.

## Estable y Beta

- **Estable**: las versiones normales. Es lo que conviene a casi todos.
- **Beta**: versiones de prueba (marcadas *Pre-release*), con novedades antes y algún error posible. Sus archivos llevan `beta` en el nombre.

Se cambia en Configuración → Sistema → Canal. Volver a Estable no baja de versión: esperás la próxima estable.

## Desinstalar

Configuración de Windows → Aplicaciones → Tomatask → Desinstalar. Tus datos (tareas, sesiones) quedan en `%LOCALAPPDATA%\Tomatask`; borrá esa carpeta si querés quitarlos también.
